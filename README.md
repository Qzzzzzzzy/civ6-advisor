# civ6-advisor · 文明6 实时军师

实时读取你正在玩的《文明6》对局，分析局势，告诉你**这回合该做什么**。

- **只读**：不会替你操作游戏，所有决定由你自己做
- **不开天眼**：只使用你在游戏里看得到的信息（战争迷雾外的东西一律不读）
- **规则引擎 + 大模型**：代码先做"体检"，算出威胁、闲置、浪费、风险；大模型再结合文明特性和胜利路线给出建议

底层的游戏连接复用了 [lmwilki/civ6-mcp](https://github.com/lmwilki/civ6-mcp)（MIT），通过游戏自带的 FireTuner 调试端口（TCP 4318）注入 Lua 读取数据。

---

## 一、快速开始：启动器（推荐）

双击 **`启动军师.bat`**，或者打包好的 `Civ6Advisor.exe`（打包方法见下面）。

启动器做的事：

1. **检查环境**：找到游戏配置文件，显示当前的显示模式、Tuner 是否开启、SDK 是否安装、游戏是否在运行
2. **自动改设置**：把游戏切到**无边框全屏**并打开 Tuner。改之前会先备份，点「恢复原始游戏设置」就能还原
3. **启动游戏**：通过 Steam 启动文明6
4. **弹出悬浮窗**：盖在游戏上，进入对局后自动连上，每回合刷新建议

> **为什么要改成无边框全屏？** 独占全屏时游戏会独占整个屏幕，任何外部窗口都显示不出来。无边框全屏看起来和全屏完全一样，只是不再独占屏幕，悬浮窗就能叠在上面。在 Win10/11 上两者的性能差别很小。

第一次用之前还需要手动做一件事：

- **安装 SDK**：Steam 库 → 左上角筛选"工具" → 安装 `Sid Meier's Civilization VI SDK`（Tuner 服务在 SDK 里，不在游戏本体里）

其他要求：
- 需要**风云变幻（Gathering Storm）** DLC
- 开启 Tuner 的存档**不能拿 Steam 成就**
- 游戏配置文件要游戏至少正常启动过一次才会生成

### 悬浮窗操作

- **按住窗口任意位置拖动**，右下角拉伸，滑块调背景透明度，位置会自动记住
- **右下角托盘图标**：单击显示/隐藏；右键菜单有 鼠标穿透、地图插旗（实验）、AI 军师开关、窗口位置复位、**退出**。悬浮窗上的「—」和 Alt+F4 只是隐藏到托盘
- **文明卡片**：文明名、领袖、擅长方向标签，加一行当前阶段重点；点一下展开文明能力（每项一句话摘要，鼠标悬停看游戏里的原文）
- **城市生产板块**：顶部汇总开拓者、建造者各「已有几个 · 在造几个」（都为 0 时标橙）；下面每座城一行，首都 ★ 排第一，显示在造什么、还要几回合。空闲的城市标红，并推荐造什么（开拓者 / 建造者 / 军事单位 / 城墙 / 侦察兵 / 纪念碑 / 粮仓 / 专业区），推荐只会从这座城当前真正能造的项目里选。依据包括：城市数是否达到文明目标（已算上在路上和在造的开拓者）、全国有没有建造者、附近有没有敌军、文明倾向（比如需要宗教的文明先建圣地）。点城市行，镜头会跳过去
- **科技 / 市政板块**：正在研究的显示进度条、剩余回合和"之后建议研究什么"；没选的会标红，并给出推荐、理由和备选。推荐会综合考虑文明倾向（俄罗斯先占星术、朝鲜先书写）、局势（敌军压境→防御科技，还在酋邦→法典，有没改良的奢侈品→对应科技，宜居度为负→竞技场相关）、尤里卡/鼓舞和回合数。鼠标悬停能看到完整理由和尤里卡/鼓舞的触发条件
- **点一条建议**：游戏镜头移到相关格子。托盘里打开「地图插旗（实验）」后，还会在这些格子上插**地图标记**（游戏自带的图钉，名字以「军师·」开头）并飘一行说明。建议里的位置都写成"西安东北 3 格"这种说法（游戏默认不显示坐标）
- **地图插旗（实验，默认关闭）**：开启后每回合自动给前几条建议涉及的格子插标记。从 Tuner 修改地图标记可能让游戏崩溃，遇到闪退请保持关闭。军师只删除自己插的标记，不会动你自己的图钉；退出时会自动清掉
- **AI军师**：开关。开启后 AI 在关键回合自动按你的文明和局势给攻略，还能在下方提问；关闭时只用本地分析

标记图标：✕ 敌军　● 推荐城址　▲ 建议移动到的位置　◆ 待改良的资源

| 快捷键（游戏里也能按） | 作用 |
|---|---|
| `Ctrl+Shift+F1` | 鼠标穿透开/关：穿透时点击直接落到游戏上，窗口会变得更透明 |
| `Ctrl+Shift+F2` | 显示 / 隐藏 |
| `Ctrl+Shift+F3` | 问 AI |

### 本地资料库（填好 API Key 就能用，不需要别的）

- **游戏资料**：第一次进入对局时自动从游戏里导出所有文明、领袖、单位、建筑、奇观、区域、改良设施、资源、科技、市政、政策、政体、信条、总督、项目的名字、完整描述、数值、前置条件、替代关系和相邻加成，用的是你游戏的语言，DLC 和模组也包含在内。保存在 `用户目录\.civ6-advisor\game_kb.json`，大约 10-30 秒。换了模组后会自动重建，也可以在托盘菜单里手动「重建资料库」
- **攻略库**：随软件打包的中文攻略（每回合决策顺序、开局、扩张、改良、区域相邻、尤里卡、政体政策、宗教、宜居住房、忠诚、时代、城邦、贸易、战争、伟人、各胜利路线、总督）+ 50 个文明的打法
- **文明攻略库**（`knowledge/civs/*.md`）：每个文明一篇详细攻略，主要整理自 Zigzagzigal 的风云变幻各文明指南。结构统一：速览（胜利倾向评分、出生倾向）、领袖差异、开局、关键时机、特色怎么用、推荐政体/政策/总督/万神殿/奇观、各胜利路线、弱点、**局势 → 建议**、对手是这个文明时怎么反制。问 AI 时会自动附上本文明攻略里最相关的段落；AI 也能用工具查对手文明的攻略。想改打法直接编辑对应 md 即可（说明见 `knowledge/civs/README.md`）
- **AI 怎么用**：问 AI 时自动附上和本局相关的条目；AI 觉得不够时还会自己调用「查资料」工具去查（悬浮窗会显示"正在查：XXX"）。模型不支持工具调用时自动退回只附资料的方式
- 悬浮窗底部有**提问框**，可以直接问"奥罗莫骑兵怎么用""下一座城放哪"。点输入框才会临时接管键盘，回车或 Esc 后焦点还给游戏

### 建议之间互相一致

- 每回合先读一份共同事实：已研究的科技/市政、领土内**看得见**的每个未改良资源（类别、用什么改良、缺哪个科技）
- 建造者建议只让你去改良**现在就能改**的资源；都缺科技时会明确说"暂时没有可改的"，并告诉你科技的先后和等待期间建造者该干什么
- 科技推荐会写明"能改良某城的奢侈品某某"，奢侈品权重高于加成资源；建造者闲着时这类科技再加权
- 时间窗口优先：需要宗教的文明在还没圣地、名额还在时，占星术会排在改良科技前面（资源晚几回合改只是少一点产出，宗教名额错过就整局拿不到）
- 推荐理由按分量排序，第一条就是最关键的原因

### 按文明定制

内置 50 个文明的攻略（原版 + 迭起兴衰 + 风云变幻 + 新纪元季票），部分文明还按领袖区分。规则引擎会跟着文明调整：

- 宗教：俄罗斯、印度、波兰这类必需宗教的文明会更早、更强烈地提醒；阿拉伯（保底先知）、刚果（不能创立宗教）不提醒
- 扩张：罗马前期目标约 8 座城，玛雅要求城市集中在首都 6 格内
- 生产建议：马里、葡萄牙提示用钱买建筑；按胜利倾向推荐先建哪种专业区；高卢提醒专业区不能挨市中心，越南提醒要建在森林/雨林/沼泽上
- 巴比伦不提示"科研垫底"，改成提示去触发哪些尤里卡
- 每回合给一条当前阶段的文明重点

没收录的文明（比如模组文明）会显示游戏里读到的能力，并建议开启「AI军师」。

### 本地建议点名到具体操作

不开 AI 也会直接告诉你"插哪张卡、选哪个、派给谁、买什么"（规则整理自 CivFanatics、theahura 指南、Comrade Kaine 万神殿指南、文明6吧过神思路）：

- **政策卡**：每个槽推荐具体的卡和理由（在造开拓者→殖民，附近有蛮族→纪律，没万神殿→神王……），并提示什么时候能免费换。
- **万神殿**：按城市周围 3 格的地形和资源（沙漠、冻土、雨林、牧场、种植园……）给出推荐，攒够信仰就提醒。
- **总督**：推荐任命谁、放哪座城（被威胁的城→维克托，忠诚在掉→阿玛尼，铺城→马格努斯…），全部任命后推荐升哪个头衔。
- **使者**：点名城邦，按路线类型和离 3 个/宗主还差几个排序。
- **金币**：用游戏给的金币价格算，直接说"在哪座城花多少钱买什么"，钱不够不推荐。
- **铺城节奏**：按 T30 两座、T50 三四座、T70 六座左右的参考提醒落后。
- **尤里卡**：推荐科技时写出尤里卡条件；快研究完但没触发时提示可以先换。
- **区域选址**：空闲城市推荐建区域时，直接查出相邻加成最高的格子（如「西安东北 2 格，科研 +3」），点建议镜头就移过去。
- **建议不打架**：金币建议要在某城买的东西，空闲城市的推荐会改成"买它，锤子去造下一个"；每座城一回合只建议买一样。
- **提前备战**：关系差、军力是你 1.5 倍以上的邻居会提醒（用游戏统计的军力，同一口径）。

### 出问题时：诊断报告

军师对游戏的每一次读取都会记到 `~/.civ6-advisor/steps.log`（开始、结束、耗时，每行立即写盘）。
游戏如果在某次读取时崩溃，下次打开军师会提示"上次运行停在「某一步」"。
托盘菜单「导出诊断报告」会把环境、显示设置、最近的读取记录整理成 `诊断报告.txt` 并复制到剪贴板，直接发给开发者即可。

### AI 军师开关

标题栏的「AI军师」是个开关（也可以用托盘菜单或 Ctrl+Shift+F3）：

- **开启**（按钮变蓝）：马上分析一次，之后在关键回合自动给攻略——出现新的紧急/重要情况、流派进入下一步、或者 8 回合没分析过时。下方会出现提问框，可以随时追问。
- **关闭**：只用本地分析（规则、科技市政、生产推荐、流派进度），不调用大模型。

开关状态会记住，下次打开保持一致。悬浮窗隐藏时不会自动分析。

### 流派按钮

每个文明有一个固定的推荐流派，显示在文明卡片里，比如澳大利亚「马格努斯砍树飞天流（魅力学院）」、苏美尔「开局战车速攻」、俄罗斯「修道院宗教流」。

- **点一下开启**：按钮变蓝，下面显示流派思路和里程碑进度（如「2/7 · 下一步：任命马格努斯」）。
  - 科技、市政推荐按流派路线加分，下一个里程碑要的科技额外加分；
  - 城市生产推荐按流派加分（城市被威胁时不加，防守优先）；
  - 建议列表多一条「流派下一步」；超过建议回合（按标准速度折算）会标「已落后」并提高优先级；
  - 流派前提没了（比如宗教名额被抢光）会提醒你取消或转型；
  - 问 AI 时附上流派说明和进度，AI 按流派给本回合安排。
- **再点一下取消**：恢复常规推荐。
- 开关按文明记住，下次打开同一个文明会自动恢复。
- 流派定义在 `src/civ6_advisor/playstyles.py`，可以照着格式改或换成自己喜欢的流派。

支持的大模型（任何 OpenAI 兼容接口都行）：

| 服务 | 接口地址 | 模型 |
|---|---|---|
| DeepSeek（默认） | `https://api.deepseek.com/v1` | `deepseek-flash` |
| 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 本地 Ollama | `http://localhost:11434/v1` | 你的模型名（Key 随便填） |

## 二、安装与打包

需要 Python 3.12+ 和 [uv](https://docs.astral.sh/uv/)。

```powershell
cd civ6-advisor
uv sync --extra overlay
```

**打包成 exe**：双击 `build_exe.bat`，生成 `dist\Civ6Advisor.exe`。之后单独拷走这个 exe 就能用，不需要再装 Python。

不开游戏先看效果（演示数据）：

```powershell
$env:CIV6_ADVISOR_MOCK="1"; uv run --extra overlay civ6-launcher
```

## 三、其他用法

### 接入 Claude Desktop（MCP）

编辑 `%APPDATA%\Claude\claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "civ6-advisor": {
      "command": "uv",
      "args": ["run", "--directory", "C:\\path\\to\\civ6-advisor", "civ6-advisor"]
    }
  }
}
```

重启 Claude Desktop，进入对局后问它"这回合我该干嘛"，或者选用内置的 **「军师」** 提示词。

### 命令行

```powershell
uv run civ6-advisor watch   # 常驻终端，每进入新回合打印本回合最该做的 5 件事
uv run civ6-advisor brief   # 打印一次完整简报
```

## 五、规则引擎目前会检查

| 类别 | 检查项 |
|---|---|
| 军事 | 敌军逼近城市（距离、战力 vs 城防、有无驻军/城墙）、关系差的文明在边境集结、交战双方军力对比、残血单位身边有敌人、可晋升/可升级单位 |
| 城市 | 生产空闲、饿死/停止成长、住房满、宜居度为负、忠诚度下降及倒戈倒计时、被掠夺设施、未改良资源 |
| 经济 | 金币入不敷出（多少回合后归零）、囤积金币不花 |
| 科技文化 | 没选科技/市政、已触发尤里卡/鼓舞的打折项、空政策槽、未使用的总督头衔、总督没分配城市 |
| 外交 | 未派使者、各项产出在已相遇文明里垫底、对手科技/外交胜利逼近 |
| 宗教/时代 | 最后一个宗教名额、黑暗时代风险、接近黄金时代 |
| 扩张 | 开拓者待落城、前期城市数偏少 |

每条结果带优先级：🔴 紧急 / 🟠 重要 / 🟡 建议 / ⚪ 提示。

| 变量 | 默认 | 说明 |

## 七、项目结构

```
src/civ6_advisor/
  game.py        只读门面（白名单）+ 局势快照采集
  rules/         规则引擎：military / cities / empire / rivals
  report.py      渲染中文简报
  server.py      MCP 服务 + brief/watch 命令行
  launcher.py    启动器（环境检查、改游戏设置、启动游戏）
  gameconfig.py  读写游戏 AppOptions.txt、检测 SDK 和游戏进程
  overlay.py     透明悬浮窗（PySide6，托盘、拖动、点击跳转）
  civs.py        50 个文明的简要档案（规则引擎用）
  knowledge/civs/ 50 个文明的详细攻略（给 AI 读）
  playstyles.py  50 个文明的推荐流派（里程碑、路线加分）
  rules/playstyle.py 流派进度检查
  research.py    科技/市政推荐（按文明和局势打分）
  production.py  城市生产：首都识别、空闲推荐、开拓者/建造者缺口
  facts.py       共同事实：已研究科技、资源改良状态
  gamedb.py      从游戏导出资料库
  kb.py          资料库检索、按局势挑资料
  knowledge/     攻略文档（随软件打包）
  civ_info.py    从游戏读取文明/领袖能力
  geo.py         格子距离、方位描述
  highlight.py   地图标记（镜头移动、格子上色、飘字，只操作界面）
  names.py       单位/资源中文名
  llm.py         大模型调用（OpenAI 兼容，流式）
  mock.py        演示数据
tests/           规则测试（uv run pytest）
```

**加一条新规则**：在 `rules/` 下任意文件写一个函数，接收 `Situation`，`yield Finding(...)`，加上 `@rule` 装饰器即可。

## 八、已知限制

- **游戏同时只允许一个 Tuner 连接**：悬浮窗、MCP 服务、命令行三者同一时间只能开一个；也不要同时开着 SDK 里的 FireTuner.exe
- 无边框全屏在配置文件里对应的设置项名我没能确认，启动器会自动找名字里带 Borderless 的项。如果没找到，只会关掉独占全屏（游戏以窗口模式启动），这时进游戏在 设置→图形 里选一次「无边框窗口」，之后游戏会自己记住
- 大模型 Key 保存在本机注册表里（明文），不要在别人的电脑上保存
- **地图标记还没在真实游戏里验证**：用的是游戏自带的地图标记接口，Lua 在 Lua 5.1 里模拟测试过。镜头移动用的接口和 civ6-mcp 一样。插标记失败时状态栏会提示，其他功能不受影响
- 旧版本用透镜图层上色会让地图变灰，新版本连上游戏后会自动关掉那些图层；如果还是灰的，打开再关掉任意透镜，或存档后重新读档
- 方位描述假定地图 y 坐标越大越靠北。如果实际南北方向反了，把 `geo.py` 里的 `Y_UP` 改成 `False`
- 文明攻略是按游戏机制写的通用打法，部分领袖能力描述可能不完全准确；文明能力原文是从游戏里读的，以游戏为准
- **还没有连真实对局测试过**，目前只用演示数据验证了规则和 MCP 流程。第一次连游戏时如果某项数据读取失败，简报末尾的"数据缺失"会列出原因
- 面向单人游戏；多人联机下使用有公平性问题，不建议
- 阈值都没在真实对局里调过（比如"敌军 4 格内算威胁"），实际玩几局后需要根据手感调整
- 格子距离计算没有处理地图左右环绕，地图边缘的威胁距离可能偏大
- 悬浮窗的鼠标穿透和全局热键用的是 Windows API，我只在 Linux 离屏模式下验证了界面和逻辑，**还没在真实 Windows 上跑过**；Mac/Linux 上没有全局热键
- 读取全部数据大约需要 1-3 秒（每项都是一次 Lua 往返）
