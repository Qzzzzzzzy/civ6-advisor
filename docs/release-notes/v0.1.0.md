## 下载哪个

- **Civ6Advisor-v0.1.0.exe**：双击就能用，不用装 Python。打开后是启动器，填不填 AI 的 Key 都可以，点「启动文明6 + 军师」。
  Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」（没有买代码签名证书）。
- **civ6-advisor-v0.1.0-源码.zip**：想看代码、自己改规则的选这个。解压后双击「启动军师.bat」，第一次会自动准备环境。

要求：Windows + Steam 版《文明6》。

## 能做什么

- 悬浮窗每回合读一遍局势，告诉你这回合先做什么、为什么
- 本地打分规则：科技/市政、城市生产、政策卡、万神殿、总督、使者、金币购买、区域选址、敌军威胁……不需要 AI，免费离线
- 50 个文明的攻略和推荐流派，按你选的文明给建议
- 可选「AI 军师」：填自己的大模型 API Key（默认 DeepSeek），AI 在规则结果上综合判断，还能追问
- 只读游戏数据，不替你操作，不改存档

## 已知问题

- 还没在很多台电脑上测过；遇到游戏闪退，请在托盘菜单点「导出诊断报告」，把内容发到 Issue
- 建议来自规则和攻略整理，不一定都对，欢迎指出
