# 拜占庭（CIVILIZATION_BYZANTIUM）· 领袖：巴西尔二世、狄奥多拉

> 资料来源：游戏内机制 + 社区攻略综合（原 Zigzagzigal 指南当前无法读取）；胜利倾向为定性判断。

## 速览
- 胜利倾向：征服 + 宗教
- 一句话打法：先创教；每个信你宗教的圣城给全军 +3 战斗力（含宗教战）；击杀单位会传播宗教。没有宗教，这个文明的能力基本没用。

## 领袖差异
- 巴西尔二世：重骑兵和轻骑兵能对信你宗教的城市打满伤害；特色单位塔格玛（Tagma）给附近单位加成 → 宗教 + 骑兵征服。
- 狄奥多拉：圣地给与相邻加成等量的文化，相邻圣地的农场 +1 粮 → 宗教 + 文化发展，打仗之间可以种田。

## 开局与前期
- 圣地优先，抢宗教（重中之重）。
- 游戏与娱乐 → 竞技场（替代娱乐中心，送一个重骑兵）。
- 早出骑兵，把宗教传到对手的圣城后进攻。

## 特色怎么用
- 塔克西斯（文明能力）：每个信你宗教的圣城 +3 战斗/宗教战斗力；击杀单位在附近传播宗教；+1 大先知点。
- 竞技场：宜居 + 送重骑兵（不耗战略资源，但要维护费）。
- 德罗蒙：早期远程海军。

## 局势 → 建议
- 宗教没拿到 → 能力基本失效，加速圣地 + 占星术；必须拿到宗教。
- 攻城前 → 先让目标城信你的宗教（巴西尔骑兵满伤害）。

## 对手是拜占庭时
- 抢宗教名额；守住自己的圣城不被转化；用反骑兵单位。
