# 埃及（CIVILIZATION_EGYPT）· 领袖：克利奥帕特拉、托勒密克利奥帕特拉、拉美西斯二世

> 资料来源：游戏内机制 + 社区攻略综合（原 Zigzagzigal 指南当前无法读取）；胜利倾向为定性判断。

## 速览
- 胜利倾向：文化、宗教最好（Zigzagzigal 的总结），克利奥帕特拉偏商路、灵活
- 出生倾向：河流/泛滥平原
- 一句话打法：河边的区域和奇观 +15% 产能，泛滥平原上的单位/改良/区域不受洪水伤害；狮身人面像给文化信仰。

## 领袖差异
- 克利奥帕特拉（地中海新娘）：国际商路 +4 金；别国通往埃及的商路给对方粮、给埃及金 → 商路型。
- 托勒密克利奥帕特拉：泛滥平原上的资源加粮和文化，泛滥平原旁的地块魅力不扣 → 河谷发展型。
- 拉美西斯二世：建成建筑得 15% 造价的文化，奇观 30% → 奇观文化流。

## 开局与前期
- 城建在河边，奇观和区域挨河（+15%）。
- 早期奇观有吸引力，但别牺牲扩张（Zigzagzigal 特别提醒早期奇观的机会成本）。
- 马里亚努战车弓手强但贵，适合在开阔地骚扰。

## 特色怎么用
- 伊特鲁（文明能力）：河边区域和奇观 +15% 产能；泛滥平原不怕洪水。
- 狮身人面像：+1 信仰 +1 文化（挨奇观更多），魅力 +；后期分数和旅游有用。
- 马里亚努战车弓手：远程骑射，在开阔地快速打击。

## 推荐选择
- 政体：古典共和 → 君主制/神权 → 民主
- 万神殿：河神（River Goddess）或芦苇与沼泽之女；奇观：金字塔、神谕、大图书馆、阿尔忒弥斯神庙

## 各胜利路线
- 文化：河边奇观 + 狮身人面像 + 拉美西斯文化。宗教：早圣地 + 狮身人面像信仰。商路：克利奥帕特拉多跑国际商路。

## 局势 → 建议
- 区域和奇观 → 挨河放。
- 狮身人面像 → 放在要建奇观的地块旁边。

## 对手是埃及时
- 早期奇观争夺：盯它的河边城；掠夺狮身人面像。
