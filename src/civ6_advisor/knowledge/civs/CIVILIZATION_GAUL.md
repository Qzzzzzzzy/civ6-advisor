# 高卢（CIVILIZATION_GAUL）· 领袖：安比奥里克斯

> 资料来源：游戏内机制 + 社区攻略综合（原 Zigzagzigal 指南当前无法读取）；胜利倾向为定性判断。

## 速览
- 胜利倾向：征服
- 出生倾向：铜、钻石、铁、玉、汞、盐、银等矿产资源
- 一句话打法：矿山给文化并文化炸弹抢地；奥皮杜姆（工业区替代）早出且能射击；专业区域不能挨着市中心。

## 开局与前期
- 优先采矿 + 矿山，用文化炸弹扩张领土。
- 区域规划：专业区域不能放在市中心旁边（要隔一格），和矿山相邻有加成。
- 铁器加工就能建奥皮杜姆 → 早期产能中心。

## 特色怎么用
- 矿山：+1 文化，完成时文化炸弹。
- 奥皮杜姆（替代工业区，铁器加工解锁）：早、便宜、有城防远程攻击。
- 盖萨泰（特色近战）：对更强单位更强。
- 安比奥里克斯：每个相邻己方军事单位 +2 战斗力；训练单位给文化 → 抱团作战。

## 局势 → 建议
- 区域选址 → 永远不挨市中心；挨矿山。
- 打仗 → 单位抱团推进。

## 对手是高卢时
- 掠夺它的矿山；别让它单位抱团包围你的城。
