# 德国（CIVILIZATION_GERMANY）· 领袖：腓特烈·巴巴罗萨、路德维希二世

## 速览
- 胜利倾向（满分10，文化/外交/征服/宗教/科技）：
  - 巴巴罗萨：7 / 4 / 8 / 4 / 8
  - 路德维希二世：10 / 6 / 7 / 4 / 8
- 上手难度：特色直观，同时有深度
- 出生倾向：五级河流
- 一句话打法：每座城多一个区域名额，汉萨（工业区）配商业中心和水利区域产能爆发；巴巴罗萨吃城邦，路德维希奇观+剧院走文化。

## 开局与前期
- 城市挤一点建，方便汉萨拿相邻加成。
- 科技：制陶术 → 书写 → 货币 → 学徒；早点顺路拿畜牧业、采矿等建造者科技。
- 尽早拿行会（Guilds）的「工匠（Craftsmen）」卡（汉萨相邻翻倍）；路德维希再拿城堡科技开旅游。
- 路德维希可以在泛滥平原附近先开建大浴场，不建完也能吃文化。

## 关键时机
- 区域规划从第一座城就开始：汉萨要挨着商业中心、引水渠、水坝、运河和资源。
- 巴巴罗萨：早期占城邦能便宜拿城和经验，但会积累不满并可能触发城邦紧急状态。

## 特色怎么用
- 自由帝国城市（文明能力）：每城区域上限 +1，小城也能放好几个专业区。
- 神圣罗马皇帝（巴巴罗萨）：多一个军事政策槽，对城邦 +7。
- 天鹅国王（路德维希）：奇观每相邻一个区域 +2 文化（没建完也算）；城堡科技后奇观和剧院广场相邻还给旅游。
- 汉萨（替代工业区）：每相邻引水渠/运河/商业中心/水坝 +2 锤，每两个相邻区域 +1，每个相邻资源 +1；小心间谍破坏。
- U 型潜艇：要电力不要石油；用来做隐形侦察网和沿海突袭（最弱的特色）。

## 推荐选择
- 政体：古典共和 → 商人共和国 → 共产或民主 → 合成技术官僚或企业自由主义
- 政策：工匠（Craftsmen，核心）、五年计划、城镇特许状、Insulae、美学和体育传媒（路德维希剧院）、密码学（防间谍）
- 总督：雷娜和莫克夏（用金币/信仰买区域）、马格努斯「垂直整合」适合紧凑城市
- 信条：管家（Stewardship）、喂养世界、禅修
- 城邦：布鲁塞尔（奇观产能）、维尔纽斯（路德维希旅游）、摩亨佐-达罗、马斯喀特、墨西哥城
- 奇观：摩索拉斯陵墓、桑科雷大学、大津巴布韦、泰姬陵、威尼斯兵工厂、鲁尔区、阿蒙森-斯科特站

## 各胜利路线
- 文化：路德维希最强，奇观挨着剧院广场和娱乐中心。
- 征服：产能高能爆兵；巴巴罗萨多军事槽 + 城邦加成。
- 科技：区域多利于尤里卡和太空零件，但没有直接科研加成。
- 外交：商业中心金币用于援助；煤电污染扣外交支持。宗教弱。

## 弱点与注意
- 汉萨和平时期也会被间谍破坏；路德维希的奇观被别人抢先就丢文化；煤电污染。

## 局势 → 建议
- 新城规划 → 先想好商业中心和汉萨的位置（相邻），再放其他区域。
- 学徒研究完 → 汉萨开工，配工匠卡。
- 巴巴罗萨前期旁边有弱城邦 → 可以考虑吃掉（注意不满和紧急状态）。

## 对手是德国时
- 掠夺/间谍破坏汉萨（小城更容易渗透）；抢路德维希想要的奇观；对巴巴罗萨别往边境城邦投太多使者，征召城邦军队可避开他的 +7。
