# 匈牙利（CIVILIZATION_HUNGARY）· 领袖：马加什一世

> 资料来源：游戏内机制 + 社区攻略综合（原 Zigzagzigal 指南当前无法读取）；胜利倾向为定性判断。

## 速览
- 胜利倾向：征服 + 外交
- 出生倾向：河流
- 一句话打法：隔河的区域和建筑产能 +50%；征召城邦单位能免费升级并加移动和战斗力 → 借城邦的兵打仗。

## 开局与前期
- 城建在河边，区域放在和市中心隔着河的一侧（+50% 产能）。
- 多派使者拿城邦宗主（为征召做准备）。

## 特色怎么用
- 珍珠多瑙河（文明能力）：隔河的区域 +50% 产能，建筑也加快。
- 马加什（乌鸦王）：征召的城邦单位 +2 移动、+5 战斗力，可以用钱便宜升级；宗主城邦多送使者。
- 黑军：强力骑兵，附近征召单位越多越强。
- 匈牙利骑兵：附近有盟友城邦就更强。
- 温泉浴场：特色建筑，宜居 + 旅游。

## 局势 → 建议
- 区域选址 → 隔河的一侧。
- 打仗前 → 先拿城邦宗主，征召单位当主力。

## 对手是匈牙利时
- 对它的城邦宣战，断征召。
