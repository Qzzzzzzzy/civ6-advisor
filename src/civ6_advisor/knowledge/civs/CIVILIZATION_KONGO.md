# 刚果（CIVILIZATION_KONGO）· 领袖：姆本巴·恩津加（Mvemba a Nzinga）、恩津加·姆班德（Nzinga Mbande）

## 速览
- 胜利倾向（满分10，文化/外交/征服/宗教/科技）：
  - 姆本巴：10 / 7 / 6 / 0 / 5（不能创立宗教，宗教胜利不可能）
  - 恩津加·姆班德：10 / 7 / 6 / 6 / 6
- 出生倾向：二级森林/雨林
- 一句话打法：伟大作品（遗物、神器、雕塑）产出加成，宫殿有 5 个作品槽，艺术家/音乐家/商人点 +50%；姆班扎住房巨大，城市长得很大。走文化。

## 开局与前期
- 早探索，有机会拿到遗物。
- 邻居合适的话拿寡头，用 Ngao Mbeba 速攻。
- 神学（使徒）→ 神授君权（圣米歇尔山）。
- 剧院广场较早建，学院区补科研。
- 恩津加·姆班德要建两个圣地去创教；姆本巴不能建圣地，也不能创教。

## 特色怎么用
- Nkisi（文明能力）：宫殿 5 个作品槽；遗物、神器、雕塑额外产出，主题化翻倍；大艺术家/音乐家/商人点 +50%。
- 姆本巴（宗教皈依者）：不能建圣地和创教；接受多数宗教的创始和强化信条效果；剧院广场和姆班扎送使徒；给使徒「殉道者（Martyr）」晋升，死后生成遗物。
- 恩津加·姆班德：本大陆产出 +10%，其他大陆 -15%（不要海外殖民）。
- Ngao Mbeba：升级便宜的近战单位，无视森林雨林，防远程强，适合早期速攻；在开阔地怕骑兵。
- 姆班扎（行会解锁，替代社区）：便宜，给住房、粮和金；必须建在森林或雨林；怕间谍「招募游击队」。

## 推荐选择
- 政体：古典共和（速攻用寡头）→ 商人共和国 → 民主或共产 → 数字民主
- 政策：阿哥革（速攻）、Retainers（宜居）、公共交通、遗产旅游、密码学（防间谍）
- 总督：雷娜（金币买区域）、莫克夏、平哥拉（前期）
- 万神殿：锻造之神（速攻）；姆本巴用大地女神做稳定信仰
- 信条：跨文化对话、朝圣、圣物匣、耶稣会教育、什一税（姆本巴）、大教堂和佛塔（恩津加）
- 奇观：阿帕达纳宫、圣米歇尔山、圣瓦西里大教堂、大本钟、救世基督像、艾尔米塔什、大津巴布韦、兵马俑（空中花园和金字塔抢来比自己建好）
- 城邦：马斯喀特和桑给巴尔（贸易）、埃里温和康提（遗物）、博洛尼亚（伟人点）、阿卡德（速攻）、安善（科技）

## 各胜利路线
- 文化（核心）：伟大作品、遗物、神器。外交：金币援助 + 免费使徒。征服：Ngao Mbeba + 攻城槌。宗教：只有恩津加·姆班德。

## 弱点与注意
- 姆本巴没有圣地，信仰少；对方研究启蒙运动后遗物旅游减半（除非建救世基督像）；伟大作品怕被偷。

## 局势 → 建议
- 姆本巴开局 → 不要建圣地、不要抢宗教，信仰靠万神殿和别的宗教。
- 有森林/雨林 → 别乱砍，留给姆班扎。
- 剧院广场 → 尽早，作品槽是核心。

## 对手是刚果时
- 间谍偷伟大作品、招募游击队；研究启蒙运动削弱遗物旅游。
