# 朝鲜（CIVILIZATION_KOREA）· 领袖：善德女王、世宗

## 速览
- 胜利倾向：科技最强（前几个时代通常领先，后期也有竞争力）；征服是合理备选；文化、外交、宗教弱
- 出生倾向：三级沙漠/草原/平原/冻土丘陵（书院必须建在丘陵）
- 一句话打法：书院（学院区）基础科研极高且便宜，每座城都能建一个 → 多出开拓者。

## 开局与前期
- 多出开拓者，每座新城都是一个书院。
- 直奔书写（开局森林多就先采矿）。
- 纪念碑拿文化，然后政治哲学 → 记录历史 → 自然哲学；之后冲启蒙运动拿理性主义。

## 书院放置规则
- 离市中心两格的丘陵上，周围是丘陵/草原/平原/泛滥平原，最好旁边有能种田或开矿的资源。
- 不要让其他区域挨着书院（会扣它的科研）。
- 城市间隔 5-6 格。农场（成长）和矿山（科研）要平衡。

## 特色怎么用
- 书院：基础科研高、便宜；自然哲学、理性主义进一步加成；怕间谍。
- 火车（火药解锁）：防守便宜，配城墙；进攻需要架设，最好配大将军、骑士或火枪手收尾；胸甲骑兵和野战炮出现后退役，后期升级机枪。
- 世宗（训民正音）：每个时代第一次研究科技时，获得双倍每回合科研的文化 → 配修道主义，尽量堆科研。
- 善德女王（花郎）：每个总督晋升 +3% 文化和科研 → 多拿总督头衔；总督怕间谍。

## 推荐选择
- 政体：古典共和 → 商人共和国 → 共产 → 合成技术官僚（世宗有时走君主制）
- 政策：自然哲学、理性主义、五年计划、密码学、非国家行为者
- 总督：平哥拉优先，马格努斯早期，梁和维克托有用；阿玛尼保护太空港
- 信条：跨文化对话、喂养世界、耶稣会教育
- 城邦：博洛尼亚、日内瓦、米特拉、那烂陀、塔鲁加
- 奇观：埃特曼安吉（Etemenanki）、大图书馆、佩特拉、Casa de Contratación、牛津大学

## 弱点与注意
- 书院没有常规相邻加成；间谍会偷尤里卡、瘫痪总督、破坏书院/工业区/太空港；太空项目产能偏弱。

## 局势 → 建议
- 研究顺序 → 书写最优先（除非周围全是树先采矿）。
- 新城址 → 一定要有合适的丘陵留给书院。
- 放其他区域 → 别挨书院。
- 中期 → 补工业区和产能，为太空竞赛准备；派反间谍保护书院。

## 对手是朝鲜时
- 间谍偷尤里卡和破坏；趁火车成型前早攻；骑士能追上火车，护卫舰打沿海火车。
