# 马里（CIVILIZATION_MALI）· 领袖：曼萨·穆萨、松迪亚塔·凯塔

## 速览
- 胜利倾向（满分10，文化/外交/征服/宗教/科技）：
  - 曼萨·穆萨：7 / 8 / 7 / 9 / 7（宗教、外交最强）
  - 松迪亚塔·凯塔：8 / 7 / 7 / 9 / 7（文化更强）
- 出生倾向：一级沙漠/沙漠丘陵（五级一长串矿产资源）
- 一句话打法：用产能换购买力。单位和建筑手造 -30%，但区域、奇观、城市项目不受影响；靠金币和信仰买东西，是游戏里最富的文明。

## 开局与前期
- 开局开拓者不要走超过一两回合，避开纯沙漠。
- 尽早拿万神殿：沙漠民俗（Desert Folklore，信仰）或宗教定居点（扩张）。
- 城市挤着建，优先「沙漠 + 河流」的城址。
  - 曼萨·穆萨：在一大片平坦沙漠里建一座贸易枢纽城，4 格内不要有别的城。
  - 松迪亚塔：城市尽量挤，最大化苏古巴（Suguba）收益。
- 第三座城左右建圣地，最好挨河。
- 推对外贸易：曼萨·穆萨攒约 170 金，解锁后马上买商人。
- 早出一个投石兵防蛮族；金币够了就买开拓者。

## 特色怎么用
- 吟游诗人之歌（文明能力）：挨着市中心的沙漠地块 +1 粮 +1 信仰；单位和建筑手造 -30%（区域、奇观、城市项目不受影响）；学徒科技之前矿山 -1 锤 +4 金。
- 苏古巴（货币解锁，替代商业中心）：每相邻圣地 +2 金、挨河 +2、每两个相邻区域 +1；该城金币和信仰购买便宜 20%，市场/银行/证券交易所能用信仰买。
- 曼德卡卢骑兵（马镫）：10 铁，55 战斗力；主要价值是 4 格内的商人不会被掠夺。研究弹道学后手里保持 10-19 铁还能继续造。
- 曼萨·穆萨（萨赫勒商人）：国际商路按起点城的平坦沙漠数 +1 金；每个黄金/英雄时代 +1 商路容量。
- 松迪亚塔（索戈隆）：金币赞助伟人便宜 20%；写作伟大作品 +4 金 +2 锤；市场有 2 个写作作品槽。

## 推荐选择
- 政体：古典共和 → 神权 → 民主 → 合成技术官僚（非文化路线）/ 数字民主（文化路线）
- 政策：殖民、土地测量员（曼萨）、城镇特许状、自由市场、Simultaneum、经济联盟
- 总督：雷娜（「承包商」金币买区域）、莫克夏（「神圣建筑师」信仰买区域）
- 信条：圣战士团、职业道德、朝圣、武僧、Dar-e Mehr、合唱音乐（Choral Music）
- 奇观：金字塔、神谕、巨像（曼萨）、阿帕达纳宫（松迪亚塔）、杰贝尔·巴卡尔、泰姬陵（奇观不受产能惩罚，可以手造）

## 各胜利路线
- 宗教（最强）：信仰多、宗教单位便宜。
- 文化：信仰赞助艺术家等伟人，苏古巴折扣；松迪亚塔更适合。
- 外交：金币做援助类紧急状态和竞赛很轻松。
- 征服：在前线直接买兵；曼德卡卢是小优势。
- 科技：自由探究可行，但太空项目不能用钱买。

## 弱点与注意
- 产能惩罚和弱矿山拖慢奇观以外的基建；曼萨的商路收入打仗时怕掠夺；太依赖沙漠。

## 局势 → 建议
- 城市生产 → 锤子用来造区域、奇观、城市项目；单位和建筑用金币/信仰买。
- 圣地和苏古巴 → 放在一起（+2 金）。
- 太空竞赛阶段 → 提前规划高产能城市，因为项目买不了。

## 对手是马里时
- 掠夺它的商路和苏古巴；战争中断它的商路收入。
