# 荷兰（CIVILIZATION_NETHERLANDS）· 领袖：威廉明娜

> 资料来源：游戏内机制 + 社区攻略综合（原 Zigzagzigal 指南当前无法读取）；胜利倾向为定性判断。

## 速览
- 胜利倾向：科技为主，文化/外交可选
- 出生倾向：二级河流
- 一句话打法：沿河的学院区、剧院广场、工业区额外加成；港口建成时文化炸弹；圩田把浅海变成可耕地。

## 开局与前期
- 城建在河边，规划「河 + 学院区 + 剧院广场 + 工业区」紧凑布局。
- 沿海城早建港口（文化炸弹抢海面）。

## 特色怎么用
- 大河（文明能力）：挨河的学院区、剧院广场、工业区 +2 相邻；港口完成时文化炸弹相邻地块。
- 圩田（特色改良）：浅海地块上建，给粮/锤/金；相邻圩田更多 → 成片建。
- 七省联合号：文艺复兴强力海军远程，打城有加成。
- 威廉明娜（奥兰治电台）：国内商路起点城 +2 忠诚，国际商路 +2 文化 → 多跑商路。

## 推荐选择
- 政体：古典共和 → 商人共和国 → 民主
- 奇观：大灯塔、巨像、鲁尔山谷

## 各胜利路线
- 科技（主线）：河边学院区 + 工业区。文化：河边剧院广场 + 商路文化。外交：商路和金币。

## 局势 → 建议
- 区域选址 → 优先挨河；沿海城优先港口（文化炸弹）。
- 缺粮的海边城 → 圩田。

## 对手是荷兰时
- 抢它的河边地；海战针对七省联合号。
