# 挪威（CIVILIZATION_NORWAY）· 领袖：哈拉尔·哈德拉达（国王版 Konge / 瓦兰吉版 Varangian）

## 速览
- 胜利倾向（满分10，国王 / 瓦兰吉）：征服 10/10 · 宗教 7/7 · 文化 6/6 · 科技 6/6 · 外交 5/8
- 出生倾向：三级海岸，五级森林
- 一句话打法：早期海军和沿海突袭，中世纪狂战士陆战；木板教堂配森林出信仰。

## 开局与前期
- 国王哈拉尔：沿海就研究航海术，在对手造海军前早出维京长船（+7 时代分）；然后占星术 + 圣地，再直奔军事战术出狂战士。
- 瓦兰吉哈拉尔：先研究占星术，早建圣地，万神殿选神圣之光确保拿到大先知。

## 特色怎么用
- 克纳尔（文明能力）：造船术后可以过深海；海军近战单位在中立海域每回合回 10 血；上下船便宜。
- 维京长船：35 战斗力、快，适合探索和沿海突袭。
- 沿海突袭（国王）：在海岸地块剩 3 移动力以上才能突袭；掠夺矿山得科研，掠夺营地/牧场/种植园/采石场得文化。
- 狂战士：48 战斗力，进攻 +10，防守近战 -5，在敌方领土 +2 移动；配攻城和夹击大胆进攻。注：狂战士掠夺有 bug 要花 3 移动力。
- 木板教堂：每相邻森林 +1 信仰，每个沿海资源 +1 锤；瓦兰吉版每回合 +1 影响力。
- 瓦兰吉卫队（瓦兰吉版）：单位维护 -2 金，征召城邦单位便宜 75%。

## 推荐选择
- 政体：两版都先寡头 → 国王：神权 + 大师礼拜堂；瓦兰吉：君主制（影响力 +50%，外交部）→ 法西斯（战争）/ 民主（宗教或外交）→ 企业自由主义或合成技术官僚
- 政策：海事工业或强征（海军产能）、征兵、封建契约（狂战士更快）、突袭、圣典；瓦兰吉加纪律、魅力领袖、商人联盟
- 万神殿：海洋之神（产能）、极光之舞（冻土森林）、神圣之光（早宗教）；职业道德配森林相邻；黄金时代可选福音传播
- 总督：阿玛尼「傀儡师」拿宗主国（瓦兰吉）；伟人：希尔德加德（圣地科研）

## 各胜利路线
- 征服（最强）：狂战士战争 + 沿海突袭拿产出。宗教：多森林圣地 + 狂战士打下的城。文化：国王掠夺得文化推市政。科技：国王掠夺矿山（看地图和对手修不修）。外交：瓦兰吉用木板教堂影响力拿使者。

## 弱点与注意
- 狂战士防守弱，被火枪手压制；打下的沿海城忠诚难保；征召单位不稳定；长船打城墙吃力；木板教堂需要森林。

## 局势 → 建议
- 开局沿海 → 航海术 + 长船抢在别人造海军之前（时代分）。
- 圣地 → 放在森林多的地方。
- 中世纪 → 狂战士配攻城单位一波，趁火枪普及之前。

## 对手是挪威时
- 沿海城市要有城墙和驻军；早造海军拦长船；狂战士防守差，主动反打它。
