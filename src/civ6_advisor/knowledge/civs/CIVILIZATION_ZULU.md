# 祖鲁（CIVILIZATION_ZULU）· 领袖：沙卡

> 资料来源：游戏内机制 + 社区攻略综合（原 Zigzagzigal 指南当前无法读取）；胜利倾向为定性判断。

## 速览
- 胜利倾向：征服
- 一句话打法：驻军城市加忠诚；攻占城市时驻军单位升级成军团/军队；军团军队更早，+5。

## 开局与前期
- 早期军队，攻占城市来滚雪球（每攻下一城，城内单位升级为军团）。
- 伊坎达（Ikanda，军营建筑）让军团军队更早更便宜。

## 特色怎么用
- 伊西洪戈（文明能力）：驻军城市 +忠诚；用有驻军的单位攻占城市会升级成军团/军队。
- 沙卡：军团和军队更早（雇佣兵 / 民族主义提前）、更强 +5。
- 因皮（Impi）：便宜的早期反骑兵近战，侧翼加成大。

## 局势 → 建议
- 攻城时 → 让要升级的单位去占城（免费升军团）。
- 防守 → 城内驻军提升忠诚。

## 对手是祖鲁时
- 早城墙；别让它在你城下组成军团。
