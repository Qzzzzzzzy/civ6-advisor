# 文明攻略库说明（给 AI 读）

每个文明一个文件，文件名是游戏内部类型名（如 CIVILIZATION_ETHIOPIA.md），程序按玩家当前文明自动挑出对应文件。

## 来源与可信度
- 主要来源：Zigzagzigal 的《文明6：风云变幻》各文明攻略（Steam 指南）和他的 Civ Summaries 总览，内容经过阅读后用中文重新整理成要点，不是原文翻译。
- 少数文件（中国、荷兰、埃及、毛利、澳大利亚、巴比伦、拜占庭、高卢、大哥伦比亚、匈牙利、印尼、高棉、玛雅、蒙古、葡萄牙、越南、祖鲁）读不到原指南，按游戏机制和社区共识整理，开头有标注，可信度较低，具体数值以游戏资料库为准。
- 胜利倾向评分是原作者的主观评分（满分 10），表示「这个文明适不适合这条路线」，不是强度排名。
- 具体数值（花费、战斗力、产出）以游戏内资料库为准；版本更新可能改动过数值。
- 政策、政体、奇观等名称写成「中文（English）」；拿不准官方中文译名时只写英文。查游戏资料库时可以用中文名或类型名。

## 每个文件的结构
1. 速览：胜利倾向评分、上手难度、出生倾向、一句话打法
2. 领袖差异（多领袖的文明）
3. 开局与前期：前 60 回合左右的优先事项
4. 关键时机：错过就亏的时间窗口
5. 特色怎么用：每项能力/特色单位/建筑的实际用法
6. 推荐选择：政体、政策卡、总督、万神殿、信条、奇观、城邦、伟人
7. 各胜利路线怎么走
8. 弱点与注意
9. 局势 → 建议：遇到某种局面时该怎么做（最适合直接用来给建议）
10. 对手是这个文明时怎么反制

## 用法提醒
- 给建议前先看「关键时机」和「局势 → 建议」，再结合当前回合的局势简报。
- 攻略是通用打法，地图和对手不同时要灵活调整：攻略说"优先 X"，但本回合有更紧急的事（敌军压境、生产空闲），先处理紧急的。
